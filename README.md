## Курсовая работа: интеграция с API для сбора данных о самолётах

**Цель:** написать Python‑проект (в ООП, с соблюдением части принципов SOLID), который через API собирает данные о самолётах, обрабатывает их и сохраняет в файл.

---

### Ключевые технологии

- **API:** `nominatim.openstreetmap.org` (координаты стран), `opensky-network.org` (данные о самолётах)
- **Библиотека:** `requests`
- **Формат хранения:** JSON (обязательно), опционально — CSV/Excel/TXT

---

### Основные шаги

- **Абстрактный класс для API + наследник:** подключение к обоим сервисам, получение координат страны (`boundingbox`) и данных о самолётах.
- **Класс `Aeroplane`:** минимум 4 атрибута (страна, позывной, скорость, высота и т. д.), валидация данных, методы сравнения по скорости/высоте.
- **Абстрактный класс для работы с файлами + класс `JSONSaver`:** методы добавления/получения/удаления записей; неиспользуемые методы — заглушки (для будущей интеграции с БД).
- **Функция `user_interaction()`:** консольный ввод (страна, топ‑N по высоте, фильтрация по стране регистрации, диапазон высот), вызов логики фильтрации/сортировки/вывода.
- **Сборка и тесты:** объединить компоненты, покрыть функционал тестами.

---

### Требования (ООП / SOLID)

- Наследование для API‑классов.
- Инкапсуляция в классе самолёта + сравнение объектов.
- Соблюдение минимум двух принципов SOLID.

---

### Выходные данные

- JSON‑файл с информацией о самолётах.
- Отфильтрованные и отсортированные данные в консоли.
